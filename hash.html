6.3 Búsqueda por funciones de HASH

Una tabla hash transforma la clave en un índice de un arreglo mediante una función hash. Idealmente, la búsqueda, inserción y eliminación se realizan en tiempo O(1) promedio.

A Función hash

Una función hash h mapea una clave a un entero en el rango [0, m), donde m es el tamaño de la tabla.

Propiedades deseables

  • Determinista: misma clave → mismo índice.
  • Uniforme: distribuye las claves de forma pareja en las casillas.
  • Rápida de calcular.
  • Minimiza colisiones (dos claves distintas con el mismo hash).

Ejemplos simples

# Método de la división
def hash_division(clave, m):
    return clave % m

# Para cadenas: polinomial
def hash_cadena(s, m, base=31):
    h = 0
    for c in s:
        h = (h * base + ord(c)) % m
    return h
En la práctica Los lenguajes usan funciones hash robustas (y a menudo aleatorizadas). En Python, dict y set están implementados con tablas hash.

B Colisiones

Cuando dos claves distintas producen el mismo índice, hay una colisión. Hay que resolverlas. Las dos estrategias principales:

1. Encadenamiento (chaining)

Cada casilla de la tabla es una lista (u otra estructura) de elementos que hashearon a ese índice.

tabla[0] → None
tabla[1] → [claveA] → [claveB] → None
tabla[2] → [claveC] → None
… 
class TablaHashEncadenada:
    def __init__(self, m=10):
        self.m = m
        self.tabla = [[] for _ in range(m)]

    def _hash(self, clave):
        return hash(clave) % self.m

    def insertar(self, clave, valor):
        i = self._hash(clave)
        for j, (k, v) in enumerate(self.tabla[i]):
            if k == clave:
                self.tabla[i][j] = (clave, valor)
                return
        self.tabla[i].append((clave, valor))

    def buscar(self, clave):
        i = self._hash(clave)
        for k, v in self.tabla[i]:
            if k == clave:
                return v
        return None

    def eliminar(self, clave):
        i = self._hash(clave)
        for j, (k, v) in enumerate(self.tabla[i]):
            if k == clave:
                del self.tabla[i][j]
                return True
        return False

Factor de carga α = n/m. Tiempo promedio de búsqueda ≈ O(1 + α). Si α se mantiene acotado (redimensionando), la búsqueda es O(1) promedio.

2. Direccionamiento abierto (open addressing)

Todos los elementos viven en el arreglo. Si hay colisión, se sondea otra casilla (lineal, cuadrática o hash doble) hasta encontrar un hueco o la clave. 

# Sondeo lineal: h(k, i) = (h'(k) + i) mod m
def buscar_abierto(tabla, clave, m):
    i = 0
    while i < m:
        idx = (hash(clave) + i) % m
        if tabla[idx] is None:
            return None          # no está
        if tabla[idx][0] == clave:
            return tabla[idx][1]
        i += 1
    return None

El factor de carga debe mantenerse < 1 (típicamente < 0.7) para buen rendimiento.

C Complejidad

Operación Promedio Peor caso
Búsqueda / inserción / eliminación O(1) O(n) (todas las claves colisionan)
EspacioO(m + n)

El peor caso es raro con buenas funciones hash y redimensionamiento. Por eso en la práctica se considera tiempo constante amortizado.
