📊 Comparativa de métodos de búsqueda

1 Complejidad

Método Requisito Mejor Promedio Peor Espacio
Secuencial Ninguno O(1) O(n) O(n) O(1)
Binaria Datos ordenados O(1) O(log n) O(log n) O(1)*
Hash Función hash + tabla O(1) O(1) O(n) O(m)

* Versión iterativa. La recursiva usa O(log n) en la pila.

2 Criterios de selección

Situación Método recomendado Motivo
Lista pequeña o búsqueda ocasional Secuencial Simple; no requiere preparación
Datos estáticos ordenados, muchas búsquedas Binaria O(log n) garantizado; poco espacio extra
Muchas búsquedas e inserciones/eliminaciones Hash (dict/set) O(1) promedio en todas las operaciones
Necesitas orden y rangos (vecinos, percentiles) Árbol balanceado / binaria sobre arreglo ordenado Hash no preserva orden
Lista enlazada Secuencial No hay acceso aleatorio eficiente para binaria

3 Relación con ordenamiento

Ordenar para poder usar búsqueda binaria tiene costo O(n log n). Compensa si el número de búsquedas k es grande:

  • Solo secuencial: costo total ≈ k · n
  • Ordenar + binaria: ≈ n log n + k · log n

Cuando k ≫ log n, ordenar + binaria (o usar una tabla hash) es claramente mejor.

📝 Actividad del programa Aplicar los métodos de búsqueda a un conjunto de n datos y determinar su eficiencia; elaborar cuadros comparativos de complejidad en tiempo y espacio (ordenamiento y búsqueda).
