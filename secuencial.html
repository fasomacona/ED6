6.1 Búsqueda secuencial (lineal)

La búsqueda secuencial examina los elementos de la colección uno por uno, desde el inicio hasta encontrar la clave o agotar la lista. No requiere que los datos estén ordenados.

A Algoritmo básico

def busqueda_secuencial(lista, objetivo):
    """Retorna el índice del objetivo o -1 si no está."""
    for i in range(len(lista)):
        if lista[i] == objetivo:
            return i
    return -1

# Ejemplo
datos = [4, 2, 9, 1, 7, 5]
print(busqueda_secuencial(datos, 7))   # 4
print(busqueda_secuencial(datos, 3))   # -1
CasoComparacionesComplejidad
Mejor (está al inicio)1O(1)
Promedio≈ n/2O(n)
Peor (al final o no está)nO(n)
Espacio auxiliar—O(1)

B Variante con centinela

Se coloca el objetivo al final de una copia (o en una posición extra) para eliminar la comprobación de “fin de lista” en cada iteración. Puede ganar un poco de eficiencia en implementaciones de bajo nivel. 

def busqueda_con_centinela(lista, objetivo):
    a = lista + [objetivo]   # centinela al final
    i = 0
    while a[i] != objetivo:
        i += 1
    if i < len(lista):
        return i
    return -1

C Búsqueda secuencial en lista ordenada

Si la lista está ordenada, se puede abortar antes cuando el elemento actual supera al objetivo (ya no puede estar más adelante). 

def secuencial_ordenada(lista, objetivo):
    for i, x in enumerate(lista):
        if x == objetivo:
            return i
        if x > objetivo:   # el resto es aún mayor
            return -1
    return -1

Sigue siendo O(n) en el peor caso, pero reduce el promedio cuando el elemento no está.

D Cuándo usarla

✅ Adecuada cuando

  • n es pequeño
  • Los datos no están (ni conviene) ordenados
  • Se hacen pocas búsquedas
  • La estructura no soporta acceso por índice eficiente (ej. lista enlazada)

❌ Evitar cuando

  • n es grande y se busca muchas veces
  • Se puede mantener la colección ordenada o usar hash
  • Se necesita respuesta en tiempo casi constante
